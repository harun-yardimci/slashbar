# Slashbar

A command bar for macOS. Highlight anything, press ⌥Space, type `/`.
Runs 100+ actions on your Mac and talks to the AI you already pay for —
no API keys, no new bill.

**Download:** https://slashbar.app  ·  [latest .dmg](https://github.com/harun-yardimci/slashbar/releases/latest/download/Slashbar.dmg)

Requires macOS 14+ · Apple Silicon & Intel · signed & notarized.

_This repository hosts the Slashbar landing page and release binaries. The app source is not public._
